# Bibliography

*Author: [Artur Sepp](https://github.com/ArturSepp)*

This is the reference list of the [GoalBasedAllocation handbook](https://github.com/ArturSepp/GoalBasedAllocation).
Software citation: [CITATION.cff](https://github.com/ArturSepp/GoalBasedAllocation/blob/main/CITATION.cff).

Every entry below is written once, in one style: authors, year, title, venue with volume, issue and
pages, then a DOI or a stable source link. A chapter's References section copies the entries it cites
verbatim and may append a sentence on what the work contributes to that chapter;
`tests/test_docs.py` enforces the match. Add a new work here first, then cite it.

The DOIs and bibliographic fields were checked against Crossref records on 1 October 2026. An entry
ending in `[pending publisher check]` has a field that could not be confirmed from a primary record;
remove the mark once it has.
